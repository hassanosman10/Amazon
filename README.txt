BNM Flex Booker V2 - Demo

Files:
- index.html: app interface
- manifest.webmanifest: installable web app metadata
- sw.js: offline cache service worker

To install as an iPhone home-screen web app:
1. Upload these files to a web host with HTTPS.
2. Open the hosted index.html in Safari on iPhone.
3. Tap Share > Add to Home Screen.

This is a local demo. It does not connect to Amazon Flex, retrieve live offers, or book blocks. Offers are entered manually. Settings, entered offers, and history are stored in browser local storage on that device.
